## 1. ภาพรวม

### 1.1 ที่มาและปัญหา
แก๊งเพื่อนไปเที่ยวโตเกียวด้วยกัน (ทริป 09 – 15 Dec 2026) ข้อมูลทริปเดิมกระจายอยู่หลายที่ — แชท LINE, โน้ต, สเปรดชีต ทำให้:
- ไม่มีที่เดียวที่เห็นแผนเที่ยวรายวันล่าสุด ใครแก้แล้วคนอื่นไม่รู้
- ไม่รู้ว่ากิจกรรมไหนต้องจองล่วงหน้า จองแล้วหรือยัง ใครเป็นคนจอง
- หารค่าใช้จ่ายยาก มีทั้งเงินเยนและบาท มีคนออกแทนก่อน ต้องคิดว่าใครค้างใครเท่าไหร่
- ของที่แต่ละคนอยากซื้อ และของที่ต้องเตรียมก่อนเดินทาง ไม่มีที่ติดตาม

### 1.2 เป้าหมายทางธุรกิจ
| # | เป้าหมาย | ตัวชี้วัดความสำเร็จ |
|---|---|---|
| G1 | รวมแผนทริปไว้ที่เดียว ทุกคนเห็นข้อมูลชุดเดียวกัน | สมาชิกทุกคนใช้แอปแทนการถามในแชท; การแก้ไขเห็นถึงกันภายใน ~15 วินาที |
| G2 | ไม่พลาดการจองที่ต้องทำล่วงหน้า | ทุกกิจกรรมที่ต้องจองมีสถานะชัดเจน และไม่มีรายการ "ยังไม่จอง" ค้างก่อนเดินทาง |
| G3 | หารเงินโปร่งใส จบทริปเคลียร์เงินได้ทันที | สรุปยอด "ใครโอนให้ใคร เท่าไหร่" ได้ในหน้าเดียว |
| G4 | เตรียมตัวและช้อปปิ้งครบ | Checklist และ Wishlist ของทุกคนติ๊กครบก่อน/ระหว่างทริป |
| G5 | ใช้งานบนมือถือได้สะดวก | เปิดจากหน้าจอโฮม iPhone ได้ ใช้งานได้ทั้งโหมดสว่าง/มืด |

### 1.3 ขอบเขต
**อยู่ในขอบเขต**
- ทริปเดียว (หนึ่งชุดข้อมูล) ที่สมาชิกในแก๊งใช้ร่วมกัน
- แผนเที่ยวรายวัน, การจอง, เที่ยวบิน/ที่พัก, ค่าใช้จ่ายและการหารเงิน, Wishlist, Checklist, จัดการสมาชิกและประเภทกิจกรรม
- แชร์สรุปรายวันเป็นรูปไปยัง LINE

**อยู่นอกขอบเขต**
- หลายทริป / หลายแก๊งในระบบเดียว
- การจองหรือชำระเงินจริงผ่านแอป (แอปแค่บันทึกและลิงก์ไปเว็บจอง)
- การแจ้งเตือน (push notification) และการแปลภาษา
- ระบบบัญชีผู้ใช้แบบอีเมล/รหัสผ่าน (ใช้โปรไฟล์ + PIN แทน)

## 2. ผู้มีส่วนได้ส่วนเสียและผู้ใช้

| บทบาท | คำอธิบาย | สิทธิ์ |
|---|---|---|
| เจ้าของทริป / ผู้ดูแล | คนตั้งทริป ดูแลข้อมูลหลัก (ผู้พัฒนา) | เหมือนสมาชิก + ดูแลระบบ/ข้อมูลใน Supabase |
| สมาชิก (Traveler) | เพื่อนในแก๊ง แต่ละคนมีโปรไฟล์และ PIN 4 หลัก | ดูและแก้ไขข้อมูลได้ทั้งหมด; ติ๊กสถานะส่วนตัว (Checklist, Wishlist) ได้เฉพาะของตัวเอง |
| ผู้ชม (Guest) | คนที่อยากดูแผนแต่ไม่ได้ร่วมแก้ เช่น ครอบครัว | ดูอย่างเดียว ไม่เห็นปุ่มเพิ่ม/แก้/ลบ บันทึกไม่ได้ |

## 4. กระบวนการหลัก (Business Flow)

1. **ก่อนทริป** — ผู้ดูแลเพิ่มสมาชิกและวัน → ทุกคนช่วยลงกิจกรรม → ระบุว่ากิจกรรมไหนต้องจอง → คนจองอัปเดตสถานะและแนบหลักฐาน → ลงเที่ยวบิน/ที่พัก → ทำ Checklist และ Wishlist
2. **ระหว่างทริป** — เปิดแผนรายวัน → ติ๊ก "ไปแล้ว" → ติ๊กของที่ซื้อแล้ว → เพิ่มค่าใช้จ่ายหน้างาน → แชร์รูปแผนของวันถัดไปลงกลุ่ม LINE
3. **หลังทริป** — เปิด Budget › ภาพรวม → ดูยอดที่แต่ละคนต้องโอน → ติ๊กว่าใครจ่ายส่วนของตัวเองแล้ว

## 5. ข้อสมมติและข้อจำกัด
- ผู้ใช้เป็นกลุ่มเพื่อนที่ไว้ใจกัน PIN 4 หลักมีไว้กันกดผิดคนและกันคนนอกแก้ ไม่ได้ออกแบบให้ทนการโจมตี
- ข้อมูลทั้งทริปเก็บเป็นเอกสาร JSON เดียว เหมาะกับข้อมูลขนาดเล็ก (หนึ่งทริป, ไม่กี่สิบคน)
- ใช้บริการฟรี/ราคาต่ำ: Vercel (โฮสต์), Supabase (ฐานข้อมูล + Storage รูป)
- อัตราแลกเปลี่ยน THB/JPY ผู้ใช้กำหนดเอง ไม่ได้ดึงอัตโนมัติ

| ความเสี่ยง | ผลกระทบ | แนวทางลด |
|---|---|---|
| หลายคนแก้พร้อมกันแล้วข้อมูลทับกัน | ข้อมูลหาย | ตรวจเวอร์ชันและรวมการแก้ไขรายส่วน (ดู SRS NFR-03) |
